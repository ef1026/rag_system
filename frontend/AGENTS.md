# AGENTS.md

## Project Goal
Build polished, production-ready frontend interfaces with strong visual hierarchy, responsive behavior, accessibility, and maintainable React/Next.js code.

## Frontend Design Rules
- Use the frontend-skill when creating landing pages, websites, prototypes, app UI, dashboards, or game UI.
- Start with a visual thesis before coding.
- Avoid generic SaaS card grids unless the product is truly a dashboard.
- Use strong typography, one clear accent color, restrained motion, and real visual hierarchy.
- Prefer mobile-first responsive design.
- Test at 375px, 768px, 1024px, and 1440px.
- Preserve existing design tokens and component patterns if the repo already has them.

## Code Rules
- Prefer React + TypeScript + Tailwind unless the project says otherwise.
- Keep components small and named clearly.
- Do not introduce unnecessary dependencies.
- Run lint/build checks after changes.

## Done Means
- UI works on desktop and mobile.
- No horizontal scroll on mobile.
- Buttons and inputs have clear focus states.
- Page builds without errors.
- Summarize changed files and visual decisions.
